# Plan 03-01: Validate And Harden QR/Check-In/Counter Flows

## Goal

Make QR check-in dependable for daily class operations across backend and coach mobile flows.

## Scope

- Verify stable QR payload normalization still resolves the stored per-user QR code.
- Harden backend check-in authorization against current scheduling rules.
- Ensure check-in updates remain idempotent and continue to feed attendance/workout metrics.
- Keep coach mobile scanner behavior aligned with backend responses and cached roster state.

## Acceptance Criteria

- Primary and secondary assigned coaches can check athletes into their assigned classes.
- Unassigned admins/coaches remain blocked from checking into classes they do not coach.
- Existing duplicate check-in behavior remains idempotent and returns `ALREADY_CHECKED_IN`.
- Attendance/streak tests continue to pass.
