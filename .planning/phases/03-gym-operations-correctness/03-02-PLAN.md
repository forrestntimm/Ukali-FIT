# Plan 03-02: Align Payment Plan Logic And Athlete Filtering

## Goal

Keep payment recording and member targeting consistent across backend, admin web, and coach mobile.

## Scope

- Audit shared payment plan definitions and all plan-selection UIs.
- Ensure admin web and mobile use backend `/payments/plans` rather than local divergent presets.
- Verify athlete-targeting dropdowns use activated/real member option endpoints where intended.
- Add or tighten regression tests around payment plan codes, quantities, and athlete-only filtering.

## Acceptance Criteria

- Admin web and coach mobile expose the same payment plan codes and labels.
- Athlete payment views show available plans and payment history without conflicting terminology.
- Admin member/payment pickers do not show coaches/admins or unactivated placeholder users where athlete-only targeting is required.
